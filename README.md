# WebAR-буклет: «Логарифмічна лінійка Отреда»

Буклет створено як результат виконання лабораторної роботи з дисципліни «Операційні системи».

## Про проєкт і функціональність

Це вебзастосунок доповненої реальності (WebAR), побудований на базі бібліотек **Three.js**, **jsartoolkit5** та **THREEx ARToolkit**. При наведенні камери на маркери з буклета [`Booklet.pdf`](./Booklet.pdf) застосунок поверх реального зображення виводить відповідну ілюстрацію та автоматично запускає аудіосупровід:

- **Barcode-маркер `1`** — зображення `slide-rule.jpg` та аудіо `slide-rule.mp3`;
- **Barcode-маркер `2`** — зображення `info.jpg` та аудіо `info.mp3`;
- **Pattern-маркер `pattern-Bad_Apple.patt`** — зображення `ipatov.jpg` та аудіо `ipatov.mp3`.

## Структура репозиторію

- `index.html` — головна сторінка із запуском AR-сцени, завантаженням маркерів, текстур та аудіоконтенту;
- `Booklet.pdf` — буклет із маркерами та матеріалами для демонстрації;
- `js/`, `jsartoolkit5/`, `loaders/`, `threex/` — скрипти Three.js, ARToolkit та завантажувачі 3D-моделей;
- `data/` — калібрувальні дані камери (`camera_para.dat`) та анімація завантаження (`spin.gif`);
- `*.jpg`, `*.mp3`, `pattern-Bad_Apple.patt` — медіаресурси та кастомний AR-маркер.

## Розгортання у новому середовищі

Оскільки застосунок використовує веб-камеру (`getUserMedia`) і завантажує локальні файли через HTTP-запити, відкривати `index.html` напряму через `file://` не варто — потрібно запускати локальний вебсервер (на `localhost` або через HTTPS).

1. Клонуйте репозиторій:
   ```bash
   git clone https://github.com/To4ilochka/WebAR-NUOP_lab1.git
   cd WebAR-NUOP_lab1
   ```
2. Запустіть будь-який локальний статичний сервер у корені проєкту, наприклад:
   - через Python:
     ```bash
     python -m http.server 8000
     ```
   - або через Node.js:
     ```bash
     npx serve .
     ```
   - або через розширення **Live Server** у VS Code.
3. Відкрийте у браузері `http://localhost:8000`, натисніть на екран (щоб браузер дозволив відтворення аудіо) та надайте доступ до вебкамери.
4. Наведіть камеру на маркери з `Booklet.pdf`.
